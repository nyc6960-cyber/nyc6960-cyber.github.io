声学专项咨询

提供建筑声学设计方案审核、噪声控制方案制定、声学验收咨询、酒店品牌声学标准达标辅导、声学技术培训等定制化服务。
02
墙体隔声测试

对建筑外墙、分户墙、客房隔墙、幕墙、门窗等构件进行空气声隔声现场测量，评估隔声量并判定是否达到设计与规范要求。

依据标准：GB/T 19889.4 / GB/T 19889.5 / GB 50118
03
机电 / 空调噪声测试

暖通空调（HVAC）、给排水管道、电梯曳引机、变压器、冷却塔、风机盘管等设备运行噪声的声压级与频谱测量，定位噪声源并提供针对性降噪建议。

依据标准：GB 22337 / GB 12348 / GB/T 17249
04
空间混响测试

对厅堂、会议室、多功能厅、影剧院、体育馆等空间进行混响时间（T20、T30）及早期衰变时间（EDT）测量，评估音质并指导声学处理方案。

依据标准：GB/T 50076 / ISO 3382
05
撞击声测试

使用标准撞击器（轻质/重质）对楼板进行撞击声隔声实验室或现场测量，评价浮筑楼板、弹性面层等构造的撞击声改善效果。

依据标准：GB/T 19889.6 / GB/T 19889.7 / GB/T 19889.8
06
建筑振动测试

轨道交通、施工打桩、爆破、工业设备等振源引起的建筑物与地面振动测量，评估振动对结构安全、人员舒适度及精密仪器的影响。

依据标准：GB 10070 / GB 10071 / GB/T 50355

工作流程

标准化流程，确保每一次测试的专业与可靠

📋

1. 需求沟通

了解项目背景、测试目的、参考标准及工期要求，确定测试方案。

📏

2. 现场测试

专业声学工程师携带校准设备到现场执行测量，记录环境参数与原始数据。

📊

3. 数据分析

数据处理、频谱分析、与标准限值比对，必要情况下进行声学模拟验证。

📄

4. 报告交付

出具正式检测报告或声学评估报告，包含测量结果、标准对比与改进建议。
